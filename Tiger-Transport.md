# Tiger Transport
<img width="128" height="286" alt="app logo" src="https://github.com/user-attachments/assets/2a828331-947f-4cd4-8bc1-0f1a02aa7514" />

**Tiger Transport** is a specialized Android application developed by Galla Transport Technologies, custom-engineered exclusively for the **Macon R-1 School District** to streamline school bus operations and enhance student safety.
## Key Features

* **Real-Time Manifest Tracking:** Keep accurate, live records of student ridership as they board and exit vehicles.
* **Onboard NFC Scanning:** Seamlessly verify route loading and drop-offs using secure NFC card technology.
